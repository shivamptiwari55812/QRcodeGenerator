QR Code Generator

A simple React-based QR Code Generator that lets users generate, preview, and download QR codes for any text or URL.

🚀 Features

Generate QR codes instantly from user input

Preview QR code in real-time

Download QR code as an image (PNG)

Clean and minimal UI

🛠️ Tech Stack

React – Frontend framework

react-qr-code – QR code generation

html2canvas – Export QR code as an image

📦 Installation

Clone the repository:

git clone https://github.com/your-username/qr-code-generator.git
cd qr-code-generator


Install dependencies:

npm install


Start the development server:

npm run dev

📸 Usage

Enter any text or URL in the input field.

Click Generate to display the QR code.

Click Download to save the QR code as an image.
